# 四类领星 API 数据接入验收（开发候选）

验收日：2026-10-29。分支：`dev/lingxing-api-foundation`，变更基线 `0e7e4fe`，开发版本 `0.2.0-alpha.2`。这是开发分支验收，不代表合入 main 或正式部署。南斗没有修改；没有新增定时任务、采购单、发货单或库存业务写入。

## 实现与实测范围

沿用现有宿主签名客户端、外置数据目录、隔离 Python 环境和面板渲染链，没有增加第三方依赖。当前 MCP 连接重新查询得到两个授权店铺；OpenAPI 返回行再次按该范围过滤。真实业务明细、请求审计、缓存、截图和候选面板均保存在操作方外置目录，不随代码提交。

| 数据 | 本次实际读取 | 结果 |
|---|---:|---|
| 产品规则 | 102 个去重 SKU | 箱规、各报价 MOQ、官方组合关系进入面板；零值/歧义不冒充有效规则 |
| FBA 货件内容 | 320 行 | ASIN、SKU、MSKU、FNSKU、申报/本地实发/FBA 已收分列 |
| 采购 | 581 行 | 逐行店铺归属、预计自有仓日期、采购/待到货/入库/退换货量保留 |
| 实际收货 | 412 行 | 实际数量与完整收货时间保留；411 行精确关联采购，1 行关联到窗口外采购 |
| 货件关联 | 52 个商品、144 条商品货件关系 | 待拣货、关闭、ETA 缺失/过期与实发量问题分别保留 |

采购按创建时间、收货按实际收货时间、FBA 按创建时间查询，窗口为 2026-01-01 至 2026-10-29（FBA 请求上界为次日，接口半开区间）。完成分页是“窗口内完整”，不等于全历史无遗漏。236 次适配器只读调用成功，补查复用同日缓存；宿主客户端内部传输重试不计入此数。本次没有新增 SIF 请求。

## 核验结果

- 两票各申报 504 件的样本精确关联到发货单，状态为待拣货、本地实发为 0，不再标成未匹配，也不计入未来确认到仓。
- 已实际收到 200 件，以及另一采购单四行各 1,500 件的样本，实际收货日期分别为 10 月 24 日和 10 月 23 日。采购单仍保留 11 月预计日期，但未结量为 0，未被重复计为未来供给。
- 581 行采购中，431 行关闭、5 行尚未下单、144 行余额可核验，1 行含换货和数量异常保留待核对。自有仓预计日期不作为 FBA 到仓日期或 FBA 断货恢复日。
- 同店同 SKU 被多个 ASIN 使用时，不按销量分配 API 采购量。唯一台账用于汇总，单品引用用于查看。组件收货不加总为成品，不再次增加当前本地、海外或 FBA 库存。
- 同一完整数据集重复挂接前后产物一致；采购/收货行没有累加。真实数据验收曾发现质量提示排序不稳定，已修正并增加回归用例。
- 171 个商品仍存在。除库存投影与库存问题外，商品字段逐项一致；原 SIF/广告数据和运行批次保持一致。浏览器核验样本仍为 30 个核心跟踪词、11 个双周有效曲线，自然排名展示正常。
- 原面板导航、图表、情景计算及建议采购策略保留，四类原始事实在现有采购台账的折叠区展示。实际与预计时间在页面中明确标注，页面控制台无错误。
- 最终 Python 256 项测试通过；JavaScript 90 项通过。包含跨店铺拒绝、分页重叠、调用预算、重复行/冲突行、待发/完成/作废、退换货、组件/共享 SKU、规则刷新、失败不当作零值、重复挂接和 HTML 转义。
- 提交前复查新增验证：异常收货时间/数量不汇总成零；产品规则刷新失败清除旧 API 默认值并保留手工规则；明细输入防覆盖；计算或渲染失败保留上一份成功的四个产物。随后再次用上述真实数据缓存重放，结果一致，没有新增付费查询。
- 暂存计算解决的是计算/渲染中途失败；多文件发布仍不是文件系统事务。南斗服务化需使用不可变批次与单个当前指针，才能处理发布过程断电或磁盘异常。
- 只读 HTTP 验收：主页 200，直接索取 JSON 404，POST 写入路径 501。只监听本机回环地址，未启用原有可写审核服务。

## 保留的真实数据边界

1. 1 条本期收货来自 2025 年采购，原采购行在本次创建时间窗口外；实际收货本身仍有店铺、数量、时间。
2. 1 条采购包含换货及数量异常，余额保持未知；不能靠简单减法补成“确定在途”。
3. 77 条货件关系的 ETA 已过、24 条缺 ETA、7 条实发数量需核对；本次只有 1 个商品同时满足未来日期、正数量和当前 MCP 在途上限，进入确认到仓曲线。读取成功不等于日期质量合格。
4. 箱规和 MOQ 的零值或缺失仍需业务补齐；共享 SKU 与组合产品尚未实施跨 ASIN 分配或齐套可用量求解。
5. 通用 API 增量水位、企业权限服务、南斗连接器/应用接入、定时调度和业务执行仍不在本批交付范围。

接口、字段、宿主调用顺序见 `lingxing-api-data-contract.md`。
